# Yll Visuals

Portfolio of Yll Mehmeti, video editor and motion designer. Vite + React, deployed on Vercel.

```bash
npm install
npm run dev      # http://localhost:5173
npm run build    # outputs dist/
```

- Text, projects, edits, AI work and contact details: `src/data.ts`
- Look and motion: `src/styles.css`
- Videos and posters: `public/media` (compressed web copies; masters stay local)
